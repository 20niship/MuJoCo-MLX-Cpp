What it is

A MuJoCo-compatible physics pipeline reimplemented as GPU compute, checked against MuJoCo C, built for reinforcement learning at scale.

MuJoCo-faithful

Pyramidal friction (condim 3/4/6), plane/box/cylinder/ellipsoid/mesh/SDF contacts, joint limits, friction loss, fixed + spatial tendons, sensors. GPU trajectories are compared against MuJoCo C in CI.

Fast where it counts

One hand-tuned solver kernel per env in shared memory, fused kinematics and Euler, GPU-side observation packing. No per-step CPU round trips.

Cameras in the loop

Every env × every camera in one indirect draw. RGB + depth land directly in CUDA tensors via Vulkan→CUDA interop. Zero CPU copy.

Drop-in for RL

Go2 environment, rsl_rl PPO training, Isaac Lab–style rewards. Also a C API (mjb.h) for Unity/C# and anything with FFI.

Physics throughput

Unitree Go2, flat ground, dt 0.005 × 4 substeps, random actions. Same hardware class, observations and rewards included.

How it works

A three-stage GPU pipeline per substep, no host synchronisation inside the loop.

qpos→Kinematics kernel→Forward / CRB / RNE→Collision (baked pair table)→Newton solver
1 workgroup per env, shared memory→Euler (direct from solver qacc)→GPU pack → torch

Backends

Vulkan compute through the mlx_vulkan (MKX) submodule. Tested on NVIDIA; CI runs on lavapipe (software Vulkan). The Metal backend was removed.

Solver

Newton with a shared-memory Cholesky direction, early exit on cost decrease, ~72 constraint rows/env. About 60–75% of GPU time.

Camera

Indirect draw of all (env, camera, geom); compute culling + vertex-clustered LOD; pack pass into (env, cam, H, W).

Verified

CPU/GPU trajectory tests, per-feature MuJoCo conformance, robustness sweeps over nv × constraint types. Details in ARCHITECTURE.md.

Get started

git clone --recursive https://github.com/20niship/MuJoCo-MLX-Cpp
cd MuJoCo-MLX-Cpp
uv sync --group build --group go2
just build-python               # Vulkan

uv run python scripts/train_go2_ppo.py --build-dir build \
  --flat --reward-preset isaac_flat --device cuda --envs 4096 --max-iterations 1500
